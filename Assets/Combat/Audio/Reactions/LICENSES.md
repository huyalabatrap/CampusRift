# Reaction audio sources

All clips in this folder are Kenney Vleugels assets under CC0 1.0, reused by P11 and P18. See the retained original licenses and [Combat asset provenance](../../LICENSES.md).

- [Impact Sounds](https://kenney.nl/assets/impact-sounds): impactSoft_heavy_000, impactMetal_heavy_001, impactBell_heavy_001 and the existing impact/glass/explosion clips.
- [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds): thrusterFire_001, forceField_003, laserSmall_001, lowFrequency_explosion_001 and the existing laser/force-field clips.

P18 uses three distinct transient/body/tail combinations:

| Reaction | Transient | Body | Tail |
|---|---|---|---|
| Wildfire Wind | impactSoft_heavy_000 | thrusterFire_001 | forceField_003 |
| Sword Soul | impactMetal_heavy_001 | laserSmall_001 | impactBell_heavy_001 |
| Guarded Absorption | impactBell_heavy_001 | forceField_003 | laserSmall_001 |
| Domain Resonance | impactSoft_heavy_000 | lowFrequency_explosion_001 | forceField_003 |

Burst text, geometry and feedback code are original Campus Rift work; no external model was added.
