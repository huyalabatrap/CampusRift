# P18 resources

No new third party model or raster asset. All eleven comic icons are the existing Campus Rift artwork at `Assets/Resources/ContentImages/Skills/<id>.png`; preserve file names and GUIDs.

- Kenney Vleugels, [Impact Sounds](https://kenney.nl/assets/impact-sounds), CC0 1.0. Reuse `impactBell_heavy_000`, glass impacts and explosionCrunch from GiantHandSeal/VoidWall and P11 Reactions. Original license files retained with those audio directories.
- Kenney Vleugels, [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds), CC0 1.0. Reuse laserSmall, forceField, thrusterFire and lowFrequency_explosion from SpeedForce, GiantHandSeal, VoidWall and Combat/Audio/Reactions. Source pages and licenses verified 2026-10-03.
- Kenney Particle Pack CC0 textures, P10 procedural flipbooks, ComicVietnamese Be Vietnam Pro font (SIL OFL 1.1), existing afterimage/URP shaders: see [P10 LICENSES](LICENSES.md) and [Combat LICENSES](../../Combat/LICENSES.md).
- Dragon, wings, willow, eye, sword circle, wire domain, humanoid soul/avatar and five-finger mountain geometry; batch shader: original procedural code authored for Campus Rift P18. No external model/rig.

Cast/loop/impact/tail audio uses prewarmed voices in SkillVfxPool and ReactionFeedback. Heavy geometry shares one batch renderer; mobile shape detail is reduced about 50%, with no gameplay change.
